# Python SDK

Version `3.0.0` of `arcanum-sdk` mirrors the direct-RPC TypeScript surface for Python agent
stacks. It uses `web3.py` and signs locally with `eth-account`.

```bash
pip install arcanum-sdk==3.0.0
```

The example is for Arc Testnet development. Keep private keys outside source control.

```python
import os
from eth_account import Account
from arcanum_sdk import ArcanumClient, arc_testnet

agent_signer = Account.from_key(os.environ["AGENT_PRIVATE_KEY"])

arc = ArcanumClient(
    wallet_address="0x0000000000000000000000000000000000000001",
    agent_signer=agent_signer,
    chain=arc_testnet,
    rpc_url=os.environ["ARC_TESTNET_RPC"],
)

result = arc.execute_usdc(
    to="0x0000000000000000000000000000000000000002",
    amount=50_000_000,
    reason="OpenAI API top-up",
    metadata={"category": "API"},
)
```

Payment-intent APIs use `reference` in place of the v2 `idempotency_key` field. It carries the
caller's stable business reference.

## Async client

```python
from arcanum_sdk import AsyncArcanumClient

async_client = AsyncArcanumClient(
    wallet_address="0x0000000000000000000000000000000000000001",
    agent_signer=agent_signer,
    chain=arc_testnet,
    rpc_url=os.environ["ARC_TESTNET_RPC"],
)
```

Both clients expose `TransferRevertedError` when a submitted chain transaction reverts. It is
distinct from `PolicyDeniedError`: callers should retain the transaction context and surface
the underlying revert reason.
